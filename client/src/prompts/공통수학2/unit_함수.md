## 유리함수 풀이 원칙

- 기본 변환: $y = \frac{ax+b}{cx+d}$ 꼴 → 분자를 분모의 배수+나머지로 변형
  $$y = \frac{k}{x-p}+q \text{ 꼴로 고친 후 → 점근선 } x=p,\ y=q \text{ 바로 읽기}$$
- 정의역: $\{x \mid x \neq p\}$,  치역: $\{y \mid y \neq q\}$
- 그래프 이동: $y = \frac{k}{x}$를 $x$축 방향 $p$, $y$축 방향 $q$ 평행이동한 것
- 점근선의 교점 $= $ 그래프의 대칭 중심: $(p, q)$
- 그래프 통과 사분면: $k>0$이면 제1·3사분면, $k<0$이면 제2·4사분면
- 두 점근선: $x = -\frac{d}{c}$, $y = \frac{a}{c}$

## 유리함수 풀이 예시

【예시52】 유리함수를 $\frac{k}{x-p}+q$ 꼴로 변환

$$y = \frac{2x+7}{x+2} = \frac{2(x+2)+3}{x+2} = 2 + \frac{3}{x+2}$$

$\therefore$ 점근선: $x=-2$, $y=2$ / 그래프는 제1·3사분면 ($k=3>0$)

【예시53】 점근선 조건으로 미지수 결정

$y = \frac{3x+b}{x+a}$ 그래프의 점근선이 $x=-2$, $y=3$이므로

$a=2$ ···①, 계수비로 $y=3$ ···②

점 $(-1,4)$를 지나면: $4=\frac{3 \cdot (-1)+b}{-1+2}=b-3$  →  $b=7$

【예시54】 유리함수의 역함수 구하기

$f(x) = \frac{4x+9}{x-1}$의 역함수:

$y = \frac{4x+9}{x-1}$로 놓고 $x$에 대해 풀기:

$y(x-1) = 4x+9$  →  $x(y-4) = y+9$

$$f^{-1}(x) = \frac{x+9}{x-4}$$

【예시55】 닫힌 구간에서 유리함수의 최대·최솟값

$2 \leq x \leq 3$에서 $y = \frac{2x-3}{x-1} = 2 - \frac{1}{x-1}$:

$k=-1<0$이므로 각 가지에서 증가

$x=3$일 때 최댓값: $y = \frac{3}{2}$,  $x=2$일 때 최솟값: $y = 1$

【예시56】 유리함수와 직선의 접선 조건

$y = \frac{k}{x+2} + 3$과 직선 $y=-x+k$가 한 점에서 만나면

두 식을 연립 후 정리하면 이차방정식이 되고

접하는 조건: $D=(k-3)^2-4(2k-4)=0$ 적용하여 $k$ 결정

【예시57】 유리함수 그래프 위의 점과 산술·기하평균

점 $P$의 좌표를 $(k,\ \frac{4}{k-2}+1)$ $(k>2)$라 하면

$PQ = k-2$, $PR = \frac{4}{k-2}$

$$PQ + PR = (k-2) + \frac{4}{k-2} \geq 2\sqrt{(k-2) \cdot \frac{4}{k-2}} = 4$$

(단, 등호는 $k-2=2$, $\therefore k=4$일 때) $\therefore$ 최솟값은 $4$

## 무리함수 풀이 원칙

- 정의역: 근호 안 $\geq 0$ 조건 먼저 구하기
  $ax+b \geq 0$  →  $x \geq -\frac{b}{a}$ ($a>0$) 또는 $x \leq -\frac{b}{a}$ ($a<0$)
- 표준 변환: $y = a\sqrt{x-p}+q$ 꼴로 변형 → 시작점 $(p,q)$ 바로 읽기
  - $a>0$이면 치역 $y \geq q$, $a<0$이면 치역 $y \leq q$
- 역함수: $y-q = a\sqrt{x-p}$ → $(y-q)^2 = a^2(x-p)$ → $x = \frac{(y-q)^2}{a^2} + p$, $x$와 $y$ 교환
- 무리함수와 직선의 교점: 무리식을 이항 → 양변 제곱 → 이차방정식 → 근 검증 필수
- $y=f(x)$와 $y=f^{-1}(x)$의 교점: $y=x$ 위에 존재

## 무리함수 풀이 예시

【예시58】 무리함수 표준형 변환 → 정의역·치역

$$y = \sqrt{-2x+6}+1 = \sqrt{-2(x-3)}+1$$

$-2(x-3) \geq 0$ → $x \leq 3$ ···① (정의역)

시작점: $(3, 1)$, 치역: $y \geq 1$

【예시59】 닫힌 구간에서 무리함수의 최대·최솟값

$1 \leq x \leq 5$에서 $y = \sqrt{2x-2}+1 = \sqrt{2(x-1)}+1$:

$x=5$일 때 최댓값: $y = \sqrt{8}+1 = 2\sqrt{2}+1$ ···①

$x=1$일 때 최솟값: $y = 1$ ···②

【예시60】 무리함수의 역함수 구하기

$f(x) = \sqrt{3x-2}+1$ $(x \geq \frac{2}{3})$의 역함수:

$y-1 = \sqrt{3x-2}$  →  $(y-1)^2 = 3x-2$  →  $x = \frac{(y-1)^2+2}{3}$

$$f^{-1}(x) = \frac{(x-1)^2+2}{3}, \quad \text{정의역: } x \geq 1$$

【예시61】 무리함수와 직선의 교점 + 근 검증

$y = \sqrt{x+3}$과 $y = x+1$의 교점:

$\sqrt{x+3} = x+1$ → 양변 제곱: $(x+1)^2 = x+3$

$x^2+x-2=0$  →  $(x+2)(x-1)=0$

검증: $x=-2$이면 $\sqrt{1}=1$이지만 $x+1=-1$ → 불성립 (버림)

$\therefore$ 교점: $(1, 2)$

【예시62】 무리함수와 역함수의 그래프 교점

$y=f(x)$와 $y=f^{-1}(x)$의 교점은 $y=x$ 위에 존재

$\sqrt{x+2} = x$  →  $x+2 = x^2$  →  $(x+1)(x-2)=0$

$x=2$ (정의역·치역 조건 확인 후 유효) $\therefore$ 교점: $(2, 2)$

【예시63】 무리함수 최솟값 + 산술·기하평균

$x>2$에서 $y = \sqrt{x-2}+\frac{4}{x-2}$의 최솟값:

$t = \sqrt{x-2}$ $(t>0)$으로 치환하면 $y = t + \frac{4}{t}$

$$t + \frac{4}{t} \geq 2\sqrt{t \cdot \frac{4}{t}} = 4 \quad (\text{등호: } t=2,\ x=6)$$

$\therefore$ 최솟값은 $4$
