## 이차방정식 풀이 원칙

- 두 근을 $\alpha$, $\beta$라 할 때 → 반드시 "근과 계수의 관계" 사용
  $$\alpha + \beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$$
- 근의 공식은 두 근의 값 자체가 필요할 때 사용
- 판별식 $D = b^2 - 4ac$:
  - $D > 0$: 서로 다른 두 실근
  - $D = 0$: 중근
  - $D < 0$: 서로 다른 두 허근
- $|\alpha| + |\beta|$ 구할 때: $\alpha$, $\beta$의 부호 먼저 판단 후 경우 나누기

## 이차방정식 풀이 예시

【예시6】 두 근 $\alpha$, $\beta$에 대한 식 계산 (근과 계수의 관계)

이차방정식 $x^2 - 5x + 3 = 0$의 두 근이 $\alpha$, $\beta$이면

근과 계수의 관계에 의하여 $\alpha+\beta = 5$,  $\alpha\beta = 3$

$$\alpha^2+\beta^2 = (\alpha+\beta)^2 - 2\alpha\beta = 25 - 6 = 19$$

$$(\alpha-\beta)^2 = (\alpha+\beta)^2 - 4\alpha\beta = 25 - 12 = 13$$

$$\frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha+\beta}{\alpha\beta} = \frac{5}{3}$$

【예시7】 두 근의 비가 주어진 경우

이차방정식 $2x^2-(k+1)x+k+3=0$의 두 근이 $1:2$이면

두 근을 $t$, $2t$로 놓으면 근과 계수의 관계에 의하여

$t + 2t = \frac{k+1}{2}$  →  $3t = \frac{k+1}{2}$  ···①

$t \cdot 2t = \frac{k+3}{2}$  →  $2t^2 = \frac{k+3}{2}$  ···②

①에서 $t = \frac{k+1}{6}$, ②에 대입하여 $k$ 결정

【예시8】 한 근이 주어진 경우

이차방정식 $x^2-(2m-3)x+m=0$의 한 근이 $4$이면

$16-(2m-3)\cdot 4+m=0$  →  $16-8m+12+m=0$  →  $7m=28$  $\therefore m=4$

$m=4$를 방정식에 대입: $(x-1)(x-4)=0$  →  나머지 한 근 $n=1$  $\therefore m-n=3$

【예시9】 이차방정식이 $k$값에 관계없이 항상 성립

방정식 $(k-3)x^2-ax+(k+2)b=0$이 $k$에 관계없이 항상 성립하면

$k$에 대한 항등식이므로: $k$의 계수: $x^2+b=0$  →  $x^2=-b$

상수항: $-3x^2-ax+2b=0$으로 연립하여 $a$, $b$ 결정

## 복소수 풀이 원칙

- 복소수 상등 조건: $a+bi = c+di \iff a=c,\ b=d$ ($a,b,c,d$는 실수)
- 켤레복소수 활용: $z = a+bi$, $\bar{z} = a-bi$ → $z\bar{z} = a^2+b^2$
- 분모의 실수화: 분모·분자에 켤레복소수 곱하기
- $x+y$, $xy$ 조건 → $x$, $y$는 이차방정식 $t^2-(x+y)t+xy=0$의 두 근

## 복소수 풀이 예시

【예시10】 분모의 실수화

$(3+2i)(3-2i) = 9+4 = 13$으로 분모 실수화

【예시11】 $z = a+bi$로 놓고 켤레복소수 활용

$z\bar{z} = a^2+b^2 = 0$이면 $a=0$, $b=0$  $\therefore z=0$

($\because$ $a$, $b$는 실수이므로 $a^2 \geq 0$, $b^2 \geq 0$)

## 여러 가지 방정식 풀이 원칙

- 삼차방정식: 조립제법으로 한 근 찾기 → (일차식)(이차식) 꼴로 인수분해
- 연립방정식 (이차+이차): 인수분해 후 경우 나누기 → 각각 대입
- 공통근: 두 방정식에 모두 대입 → 연립하여 근 결정
- $|x|$ 포함 방정식: $x < $ 기준값, $x \geq $ 기준값 구간 나누기

## 여러 가지 방정식 풀이 예시

【예시12】 연립방정식 $x+y=1$, $x^2+y^2=5$

$x+y=1$에서 $y=1-x$  ···①

①을 $x^2+y^2=5$에 대입: $x^2+(1-x)^2=5$

$2x^2-2x-4=0$  →  $x^2-x-2=0$  →  $(x+1)(x-2)=0$

$\therefore x=-1$ 또는 $x=2$  →  $(x,y) = (-1,2)$ 또는 $(2,-1)$

【예시13】 대칭형 연립방정식 $x^2+xy-2y^2=0$

인수분해: $(x+2y)(x-y)=0$

$\therefore x=-2y$ 또는 $x=y$  → 각각 나머지 방정식에 대입
