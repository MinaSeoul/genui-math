## 다항식 풀이 원칙

- 곱셈공식 변형: 주어진 조건(예: $\frac{1}{x} + \frac{1}{y} + \frac{1}{z} = 0$)을 곱셈공식에 연결
- 인수분해 전략 선택 순서:
  ① 공통인수 묶기
  ② 곱셈공식 역이용 (완전제곱식, 합차공식, $a^3 \pm b^3$)
  ③ 치환: 공통부분을 $t$로 놓기
  ④ 한 문자에 대한 내림차순 정리 후 인수분해
- 나머지 정리: $P(a) =$ 나머지, 인수 → $P(a) = 0$
- 조립제법: 삼차 이상의 인수분해에서 한 근을 찾은 후 사용

## 다항식 풀이 예시

【예시1】 $\frac{1}{x} + \frac{1}{y} + \frac{1}{z} = 0$에서 $(x+y+z)^4$의 값

풀이:

$\frac{1}{x} + \frac{1}{y} + \frac{1}{z} = 0$에서 $xy + yz + zx = 0$ ($\because xyz \neq 0$)

$$(x+y+z)^2 = x^2+y^2+z^2 + 2(xy+yz+zx) = 2 + 2 \cdot 0 = 2$$

$$(x+y+z)^4 = \{(x+y+z)^2\}^2 = 2^2 = 4$$

【예시2】 공통부분 치환 인수분해: $x^2+3x$를 $t$로 치환

$x^2+3x = t$로 놓으면

$$(\text{주어진 식}) = (t+1)(t-3) = (x^2+3x+1)(x^2+3x-3)$$

【예시3】 한 문자에 대한 내림차순으로 인수분해

$$a^2b - ac - ab^2 + bc = -(a-b)c + ab(a-b) = (a-b)(ab-c)$$

【예시4】 나머지 정리 + 연립방정식

$P(x) = x^3+ax+b$라 하면 나머지 정리에 의하여

$P(1) = 1+a+b = 1$,  $P(3) = 27+3a+b = 13$

$\therefore a+b = 0$,  $3a+b = -14$

위 두 식 연립 → $a = -7$, $b = 7$

【예시5】 조립제법으로 삼차방정식 인수분해

$P(x) = x^3-x^2+2x-4$이면 $P(1) = 0$이므로

조립제법으로 나누면 $P(x) = (x-1)(x^2+2x+4)$ (나머지 이차식은 판별식 확인)
