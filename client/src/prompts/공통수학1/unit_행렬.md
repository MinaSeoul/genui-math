## 행렬 풀이 원칙

- 행렬의 곱: $AB \neq BA$ (교환법칙 성립하지 않음)
- 단위행렬 $E$: $AE = EA = A$
- $(-E)^n$: $n$이 홀수면 $-E$, $n$이 짝수면 $E$
- $(-E)^{\text{홀}} + E^{\text{짝}} = -E + E = O$
- 두 행렬이 서로 같을 조건 → 성분끼리 등치 → 연립방정식

## 행렬 풀이 예시

【예시20】 행렬의 거듭제곱

$A^2 = A \cdot A$ 직접 계산, $A^3 = A^2 \cdot A$ 순서대로

$$(-E)^{19} + E^{50} = -E + E = O = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$$

【예시21】 두 행렬이 서로 같을 조건

두 행렬이 서로 같으면 대응하는 성분이 같으므로

$x+y=3$, $x^2+y^2=9$ (또는 $x^2=4$ → $x=\pm 2$)
