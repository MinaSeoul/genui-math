## 삼각함수 풀이 원칙

- 일반각: $2n\pi+\theta$로 정리 후 범위에 맞는 $n$ 선택
- 사분면 판단: $\sin$, $\cos$, $\tan$의 부호 조건 동시 적용
- 그래프: $y = a\sin(bx+c)+d$ → 진폭 $|a|$, 주기 $\frac{2\pi}{|b|}$, 이동 $-\frac{c}{b}$, $d$
- 삼각방정식: 일반해 구한 후 주어진 범위에서 특수해 선택

## 삼각함수 활용 (사인/코사인 법칙)

- 두 변 + 끼인각 → 코사인법칙: $c^2 = a^2+b^2-2ab\cos C$
- 세 변 → 코사인법칙: $\cos A = \frac{b^2+c^2-a^2}{2bc}$
- 한 변 + 각도 → 사인법칙: $\frac{a}{\sin A} = 2R$
- 넓이: $S = \frac{1}{2}ab\sin C$

## 삼각함수 풀이 예시

【예시26】 사분면 판단

$\sin\theta > 0$이므로 1, 2사분면 / $\cos\theta < 0$이므로 2, 3사분면

$\therefore \theta$는 제2사분면

【예시27】 삼각방정식 일반해

$\theta + 2\theta = 2n\pi + \frac{\pi}{2}$에서

$$3\theta = 2n\pi+\frac{\pi}{2} \quad \therefore \theta = \frac{2n\pi}{3}+\frac{\pi}{6}$$

$0 < \theta < \pi$에서 $n=0$ → $\theta=\frac{\pi}{6}$, $n=1$ → $\theta=\frac{5\pi}{6}$

$\therefore$ 합 $= \pi$
