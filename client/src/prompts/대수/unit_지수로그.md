## 지수 풀이 원칙

- 밑을 통일: 공통된 수의 거듭제곱으로 변환
- $a^x = b^y = k$ 꼴: $k^{1/x}$, $k^{1/y}$ 형태로 치환
- 지수방정식: 밑을 같게 만든 후 지수끼리 등치
- 지수부등식: 밑 $> 1$이면 부등호 유지, $0 <$ 밑 $< 1$이면 반전

## 지수 풀이 예시

【예시22】 $a^x = b^y = 3^z = k$ $(k>0)$ 유형

$a = k^{1/x}$, $b = k^{1/y}$, $3 = k^{1/z}$  ···①②③

$\frac{1}{x} + \frac{1}{y} = \frac{2}{z}$이면

$$ab = k^{1/x+1/y} = k^{2/z} = (k^{1/z})^2 = 3^2 = 9$$

【예시23】 지수함수 최댓값·최솟값

$y = 4^{x+1}-1$에서

$x=1$일 때 최대: $M = 4^2-1 = 15$

$x=-2$일 때 최소: $m = 4^{-1}-1 = -\frac{3}{4}$

$\therefore M+m = 15 - \frac{3}{4} = \frac{57}{4}$

## 로그 풀이 원칙

- 로그방정식: 진수 조건 먼저 확인 → 방정식 풀기 → 조건 대입 검증
- $\log x = t$ 치환: 범위도 함께 변환
- 산술평균 $\geq$ 기하평균: $\log x + \frac{양수}{\log x}$ 꼴에서 자주 활용

## 로그 풀이 예시

【예시24】 진수 조건 확인 필수

$\log_2(x-1) + \log_2 x = 1$

진수 조건: $x-1>0$, $x>0$  $\therefore x>1$  ···①

$\log_2 x(x-1) = 1$  →  $x(x-1) = 2$  →  $x^2-x-2=0$

$(x+1)(x-2)=0$  $\therefore x=-1$ 또는 $x=2$

①에 의해 $x=2$

【예시25】 $\log x = t$ 치환 + 최댓값

$y = -(\log x)^2+2\log x+1$에서 $\log x = t$로 치환

$$y = -t^2+2t+1 = -(t-1)^2+2 \Rightarrow t=1\text{일 때 최대 }2$$

$\log x = 1$  $\therefore x=10$
